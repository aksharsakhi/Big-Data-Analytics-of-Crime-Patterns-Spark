2 partitions allocated based on HDFS default block distribution.

repartition(4) [Wide Transformation]:

Triggers full network shuffle to scale concurrency across 4 worker cores.

coalesce(2) [Narrow Transformation]:

Efficiently collapses partitions without network data movement overhead.

Scala RDD Core Implementation Snippet

Extract from src/main/scala/bigdata/CrimeAnalyticsRDD.scala 
val rawRdd = sc.textFile("dataset/chicago_crimes_clean.csv")
val header = rawRdd.first()

// Transformation 1: filter (data hygiene & header elimination)
val dataRdd = rawRdd.filter(_ != header)

// Transformation 2: map (deserialize into typed CrimeRecord objects)
val crimesRdd = dataRdd.map(parseCsvLine).persist(StorageLevel.MEMORY_AND_DISK)

// Key-Value Transformation: reduceByKey for hotspot ranking
val districtCounts = crimesRdd.map(c => (c.district, 1)).reduceByKey(_ + _).sortBy(_._2, ascending = false)

// Actions: count(), take(5), reduce()
val total = crimesRdd.count()
val topHotspots = districtCounts.take(5)
